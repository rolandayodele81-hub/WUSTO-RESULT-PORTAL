# WUSTO Result Portal

A static student result portal demo that can be hosted on Vercel or Netlify.

## Run locally
Open the project folder in a static server or use a simple file server.

## Deploy
- Vercel: add the project root and deploy.
- Netlify: set the publish directory to `wesley-portal`.

## Demo access
- Portal: `/wesley-portal/index.html`
- Result checker: `/wesley-portal/student/check-result.html`
- Admin: `/wesley-portal/admin/login.html`
